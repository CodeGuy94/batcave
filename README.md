# Level Up Life

A game-like daily task tracker for real life, built with React and Vite.

## Run locally

1. Install Node.js 18+.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Included

- Daily missions with toggle completion
- XP progress toward the next level
- Streak and recent activity UI
- Responsive mobile layout
